# SAFE HOMECARE - Quick Start Guide

Get up and running with SAFE HOMECARE in minutes!

## 🚀 Quick Installation

### For Developers

```bash
# 1. Clone the repository
git clone https://github.com/jamiebsvwallet/SAFE-HOMECARE-.git
cd SAFE-HOMECARE-

# 2. Install dependencies
npm install

# 3. Start the Metro bundler
npm start

# 4. Run on Android (in another terminal)
npm run android

# 5. Run on iOS (Mac only, in another terminal)
npm run ios
```

## 📱 First Time Setup

### When You First Open the App

1. **Grant Permissions**
   - Camera: For taking photos
   - Storage: For saving media
   - Bluetooth: For sensors
   - Notifications: For alerts

2. **You're Ready!**
   - The Dashboard will appear
   - Start creating reports or connecting sensors

## ⚡ Quick Actions

### Create Your First Report

```
1. Tap "Create New Report" from Dashboard
2. Enter:
   - Title: "Kitchen Inspection"
   - Location: "Kitchen"
   - Description: "Checked all fixtures"
3. Take photos (optional)
4. Tap "Create Report"
5. Choose "Share Now" or "Done"
```

**Time: ~2 minutes**

### Connect a Sensor

```
1. Tap "Manage Sensors" from Dashboard
2. Tap "Add New Sensor"
3. Select your sensor from the list
4. Wait for "Connected" confirmation
5. Done! Sensor is now monitoring
```

**Time: ~1 minute**

### View Reports

```
1. Tap "Leak Detection Reports" from Dashboard
2. See all your reports
3. Tap any report to view details
4. Tap "Share" to send to customer
```

**Time: ~30 seconds**

## 💡 Tips & Tricks

### Reports
- ✅ Use descriptive titles
- ✅ Take multiple photos from different angles
- ✅ Include customer email for quick sharing
- ✅ Mark leak status correctly

### Sensors
- ✅ Place sensors on flat surfaces
- ✅ Keep within 30m (100ft) of phone
- ✅ Check battery levels regularly
- ✅ Test sensors after installation

### Photos
- ✅ Use good lighting
- ✅ Take both wide and close-up shots
- ✅ Show context (room + specific area)
- ✅ Capture before/after if applicable

## 🆘 Quick Troubleshooting

### Can't Connect to Sensor
1. Enable Bluetooth
2. Enable Location (Android)
3. Move closer to sensor
4. Restart app if needed

### Photo Not Saving
1. Check storage space
2. Grant camera permission
3. Grant storage permission
4. Try again

### App Crashes
1. Force close app
2. Clear app cache
3. Reinstall if needed
4. Contact support

### Notifications Not Working
1. Enable notifications in settings
2. Check Do Not Disturb mode
3. Grant notification permission
4. Restart device

## 🔔 Understanding Alerts

### Alert Types

**🚨 Leak Detected**
- Urgent notification
- Shows location
- Red status indicator
- Action: Investigate immediately

**🔋 Low Battery**
- Warning notification
- Replace battery soon
- Yellow indicator
- Action: Replace battery

**📡 Connection Lost**
- Info notification
- Sensor disconnected
- Gray indicator
- Action: Reconnect sensor

## 🔐 Permissions Explained

### Why We Need Each Permission

**Camera** 📷
- Take photos for reports

**Storage** 💾
- Save photos and videos
- Store report data locally

**Bluetooth** 📡
