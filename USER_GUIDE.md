## First Time Setup

### 1. Install the App
- Download SAFE HOMECARE from Google Play Store or Apple App Store
- Open the app after installation

### 2. Grant Permissions
When prompted, allow the following permissions:
- **Camera**: For taking photos and videos
- **Storage**: For saving media files
- **Bluetooth**: For connecting to leak detection sensors
- **Location**: Required for Bluetooth scanning (Android)
- **Notifications**: For receiving leak alerts

### 3. Initial Configuration
The app will initialize automatically on first launch.

## Creating Reports

### Step-by-Step Guide

#### 1. Start New Report
- From Dashboard, tap "Create New Report"
- Or from Reports screen, tap "+ New Report" button

#### 2. Fill in Details

**Required Fields:**
- **Report Title**: Brief description (e.g., "Kitchen Sink Inspection")
- **Location**: Where the inspection took place (e.g., "Master Bathroom")

**Optional Fields:**
- **Description**: Detailed findings and observations
- **Customer Email**: For direct report sharing
- **Leak Detected**: Check this box if a leak was found

#### 3. Add Media Documentation

**Photos:**
- Tap "📷 Add Photo"
- Choose "Camera" to take a new photo
- Or "Gallery" to select existing photo
- Add multiple photos to document different angles

**Videos:**
- Tap "🎥 Add Video"
- Record a video or select from gallery
- Useful for showing water flow or damage extent

#### 4. Save and Share
- Tap "Create Report" to save
- Choose "Share Now" to immediately send to customer
- Or "Done" to save for later sharing

## Connecting Sensors

### Setting Up AI Leak Detection Sensors

#### 1. Prepare the Sensor
- Install battery in sensor
- Place sensor in desired location
- Sensor should be on floor near potential leak sources:
  - Under sinks
  - Near water heaters
  - By washing machines
  - In basements
  - Near toilets

#### 2. Connect to App
1. Tap "Manage Sensors" from Dashboard
2. Tap "Add New Sensor"
3. Enable Bluetooth on your device
4. Sensor should appear in scan results
5. Tap sensor name to connect
6. Wait for "Connected" confirmation

#### 3. Sensor Placement Tips
- **Kitchen**: Under sink, near dishwasher
- **Bathroom**: Around toilet base, under sink
- **Laundry**: Behind washing machine
- **Basement**: Near water heater, sump pump areas
- **Water Heater**: At base of tank

### Managing Multiple Sensors
- Connect up to 10 sensors per account
- Each sensor has unique identifier
- View all connected sensors in sensor management
- Check battery levels regularly
- Replace sensors as needed

## Understanding Alerts

### Types of Alerts

#### 🚨 Leak Detection Alert
**When**: Sensor detects water
**What Happens**:
- Loud notification sound
- Push notification
- Dashboard status changes to "Leak Detected"
- Alert includes location of affected sensor

**What To Do**:
1. Check notification for location
2. Investigate immediately
3. Take corrective action
4. Create inspection report
5. Document with photos/videos

#### 🔋 Low Battery Alert
**When**: Sensor battery below 20%
**What To Do**: Replace sensor battery soon

#### 📡 Connection Lost Alert
**When**: Sensor disconnects unexpectedly
**What To Do**: Check sensor, reconnect if needed

### Alert Recipients

#### Service Provider (You)
- Receive all alerts immediately
- Can respond and document
- Create reports for customers

#### Customer
- Receives alerts via app (if they have the app)
- Gets notification with location
- Can see report when you share it

### Alert Settings

**Customize Notifications:**
1. Go to Dashboard > Alert Settings
2. Configure:
   - Alert sound
   - Vibration
   - Do Not Disturb hours
   - Emergency contacts
   - Email forwarding

## Tips and Tricks

### Photo Documentation
- Good lighting improves photo quality
- Take wide shots and close-ups
- Show context (entire room, then specific area)
- Capture before and after repair

### Report Organization
- Use consistent naming conventions
- Include property address in location
- Add dates to titles when needed
- Keep descriptions concise but complete

### Sensor Optimization
- Place sensors on flat surfaces
- Keep away from drains
- Avoid direct sunlight
- Ensure Bluetooth range (up to 30m/100ft)
- Test after installation

### App Performance
- Keep app updated
- Clear old reports periodically
- Restart app if issues occur
- Ensure adequate storage space

## Frequently Asked Questions

**Q: How many reports can I create?**
A: Unlimited reports, subject to device storage.

**Q: Can I edit a report after creation?**
A: Currently, reports cannot be edited. Delete and recreate if needed.

**Q: Do customers need the app to receive reports?**
A: No, reports can be shared via any messaging method. App installation is optional for customers.

**Q: How long do sensor batteries last?**
A: Typically 1-2 years depending on usage and sensor model.

**Q: What if my phone loses connection to sensors?**
A: Sensors continue monitoring. Reconnect when back in range to sync status.

**Q: Can I use the app offline?**
A: Yes, reports can be created offline and shared later when connected.

## Safety Information

### Important Reminders
- Leak detection is supplementary to regular maintenance
- Always address leaks immediately
- Sensors detect water presence, not leak severity
- Professional assessment recommended for major issues
- This system does not prevent leaks, only detects them

### Emergency Procedures
1. Shut off water supply if leak is severe
2. Contact plumber for repairs
3. Document damage for insurance
4. Create report in app
5. Follow up with customer
